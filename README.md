# TuRutaAmiga — Web oficial

Esta carpeta contiene una página web estática lista para subir a cualquier hosting.

## Archivos
- index.html — página principal
- style.css — diseño responsive
- script.js — menú móvil y pequeños comportamientos
- assets/icon-192.png — favicon/icono
- assets/icon-512.png — icono grande
- TuRutaAmiga.apk — APK, si fue incluido en el paquete

## Publicación
Sube todos los archivos conservando la estructura de carpetas.

Importante: el enlace de descarga espera que el APK se llame exactamente `TuRutaAmiga.apk` y esté junto a `index.html`.
